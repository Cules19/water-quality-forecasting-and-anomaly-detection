# Pipeline stages

The numbered directories are versioned workflow stages. Numbers preserve the project chronology; gaps are intentional because superseded or failed branches were removed from this curated code view.

The shortest final scientific chain is documented in [`../docs/REPOSITORY_MAP.md`](../docs/REPOSITORY_MAP.md). Stages `11`–`18`, `22`, `26`, `27`, and `29` are useful supporting baselines or sensitivity analyses. Stages `40` and `41` build consolidated reports. Stage `56` is retained for its upstream data product but explicitly stops before modelling.

Run stage scripts from the repository root. Most scripts write versioned folders below `analysis_outputs/`; that directory is intentionally ignored by Git.
